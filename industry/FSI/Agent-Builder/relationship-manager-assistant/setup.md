# Relationship Manager Assistant setup

## Environment

Use an account with access to Microsoft 365 Copilot Agent Builder and permission
to create an agent and upload knowledge sources. The demonstration uses fictional
customer data and does not require a connection to a production banking system.

## Setup

1. Open Agent Builder and create an agent named **Relationship Manager Assistant**.
2. Copy the description and instructions from [README.md](README.md) into its
   configuration fields.
3. Extract the package in `data-files/` and upload the included files as
   knowledge sources.
4. Try the sample prompts from the README. Verify the agent identifies missing
   information rather than inventing customer details.
