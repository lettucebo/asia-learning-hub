
# Retail use cases

Reusable retail demos with fictional customers and data. Start with a scenario README; agent packs also include `setup.md`. Nothing in these packs sends messages, changes orders, or deploys resources automatically.

## New demo packs

| Use case | Workload | Decision supported |
|---|---|---|
| [Returns & Product Quality Review](Copilot/Returns%20%26%20Product%20Quality%20Review/README.md) | Copilot: Chat, Excel, Word, PowerPoint, Teams, Outlook | Which evidence-backed investigations should start first? |
| [Campaign Launch Readiness](Copilot/Campaign%20Launch%20Readiness/README.md) | Copilot: Chat, Excel, Word, PowerPoint, Teams, Outlook | What blocks launch, despite a high completion percentage? |
| [Returns & Exchange Policy Coach](Agent%20Builder/Returns%20%26%20Exchange%20Policy%20Coach/README.md) | Agent Builder | Routine return route or specialist review? |
| [Click & Collect Recovery Agent](Copilot%20Studio/Click%20%26%20Collect%20Recovery%20Agent/README.md) | Copilot Studio **preparation only** | Which order needs recovery, consent, or refreshed evidence? |

The Copilot packs include ready-to-open Excel tables, readable CSV sources, exact expected figures, and short meeting role-plays. The Agent Builder pack includes two supported text knowledge files and ten acceptance cases. Studio preparation includes six sample orders, eight acceptance cases, and the required Retail publisher/solution naming.

**Verification:** Local checks cover sample data, workbook contents, expected calculations, and local documentation links; they do not prove model behavior. Tenant testing and a second-person setup check are required before sign-off. Studio additionally needs a real tested solution export and import; no export is included.
